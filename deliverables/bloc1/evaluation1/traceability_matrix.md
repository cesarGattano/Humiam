## Constats

* **Socle commun** : le récit d'un cas concret couvre les 15 rubriques. Chaque rôle, quel que soit son module, est donc interrogé sur la caractérisation, les métadonnées, l'accès, le stockage, les traitements, l'accessibilité et la sobriété de ses propres données.
* **Accessibilité** : posée à tous les rôles dans le récit (pratique), approfondie dans les modules photographe / vidéaste et nutritionniste, et côté gouvernance dans le module responsable éditorial·e (règles fixées par la ligne éditoriale).
* **Module chef cuisinier·ère** : aucune relance propre en Accès, Stockage, Temporalité, Volume ni Données. Ces rubriques reposent entièrement sur le récit du tronc commun.
* **Éco-conception** : rubrique dédiée, centrée sur la sobriété des contenus et de leur stockage, la conception du service relevant des équipes techniques. Posée à tous les rôles dans le récit (copies et versions conservées), approfondie dans le module photographe / vidéaste (poids, formats, fichiers bruts), et côté gouvernance dans le module responsable éditorial·e (sobriété fixée par la ligne éditoriale). Elle rejoint la minimisation du RGPD : ne produire et ne conserver que ce qui sert.
* **Traitements appliqués** : critère explicite de C1, porté par l'étiquette Processus. Les relances qui nomment explicitement les traitements se trouvent dans le récit du tronc commun et dans le module photographe / vidéaste.
