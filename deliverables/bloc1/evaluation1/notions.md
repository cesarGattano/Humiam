# Notions sur l'entretien

L'entretien est une phase d'enquête. C'est un outil issu de la sociologie qui permet d'obtenir des informations de façon orale de la part des personnes parties prenantes d'un projet : les « enquêtés ».

Il existe 3 approches :
* directive ;
* semi-directive ;
* non directive.

Nous nous limiterons à l'approche semi-directive.

Dans cette approche, les enquêtés sont guidés par l'enquêteur et cadrés sur des thèmes établis à l'avance, mais leur parole est laissée libre grâce à des questions ouvertes ; le rôle de l'enquêteur est d'assurer les relances. L'entretien est structuré comme un entonnoir, passant des généralités aux points précis au fil de l'échange.

La grille (ou guide) d'entretien comporte plusieurs parties :
* objectifs de l'étude (rappel pour l'enquêteur) ;
* introduction (se présenter, mettre à l'aise, faire signer les documents obligatoires, rappeler le principe) ;
* questions générales ;
* échange : questions spécifiques autour des thèmes définis à l'avance ;
* questions de fin : revenir sur ce qui a été dit, vérifier s'il y a eu des oublis ;
* conclusion : synthèse à chaud, visibilité sur les prochaines étapes.

Pour préparer une enquête, il est important de :
* poser sur le papier les questions auxquelles on souhaite répondre grâce à l'enquête ;
* réfléchir aux processus que l'on souhaite explorer durant l'enquête ;
* écrire la liste des thèmes que l'on souhaite aborder et les ordonner selon un enchaînement logique ;
* écrire des questions de démarrage pour chaque thème.
